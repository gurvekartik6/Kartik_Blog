# Kartik Yadav Gurve | Developer Blog

A personal developer blog sharing knowledge about Spring Boot, Java, Hibernate, System Design, Docker, Kubernetes, and more.

🔗 **Live Demo:** [kartik-blog.vercel.app](https://kartik-blog.vercel.app/)

---

## 📚 Topics Covered

- Spring Boot & Java
- Hibernate ORM
- System Design (Microservices, Caching, Load Balancing, Sharding, API Gateway)
- Docker & Kubernetes
- Git & GitHub
- Book Takeaways & Personal Experiences

---

## ✨ Features

- 📝 36 blog posts with search and filter
- 🏷️ Tag-based browsing
- 📊 Sort by date or read time
- 👁️ Views counter
- ❤️ Like/Unlike posts
- 💬 Comment system
- 🌙 Dark/Light mode toggle
- 📱 Fully responsive
- 🎨 3D interactive background
- 📋 Copy code with one click

---

## 🛠️ Built With

- HTML5, CSS3, JavaScript
- Bootstrap 5
- Font Awesome 6
- Three.js
- localStorage (for views, likes, comments)

---

## 🚀 Quick Start

1. Clone the repo:
```bash
git clone https://github.com/gurvekartik6/blog-website.git
```

2. Open `index.html` in your browser.

---

## 📝 Add a New Post

Edit `js/posts-data.js` and add a new object:

```javascript
{
  slug: "your-post-slug",
  title: "Your Post Title",
  excerpt: "Short description",
  image: "https://images.unsplash.com/photo-...?w=800&h=400&fit=crop",
  tags: ["Java", "Spring Boot"],
  author: "Kartik Yadav Gurve",
  date: "June 26, 2026",
  readTime: 5,
  featured: true,
  content: `<h2>Title</h2><p>Content...</p>`
}
```
